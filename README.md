# Clínica de Vóley — Hernán Ferraro

Landing page desarrollada para promocionar la clínica de vóley de Hernán Ferraro en Bahía Blanca, organizada por Club Atlético Liniers.

## 🚀 Tecnologías

* Next.js 16
* React 19
* TypeScript
* Tailwind CSS
* Framer Motion
* Lucide Icons

# Características

* Diseño responsive
* Animaciones suaves con Framer Motion
* Integración WhatsApp
* Formulario de inscripción
* Sección de agenda del evento
* Sponsors dinámicos
* Optimizado para deploy en Vercel
